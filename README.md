# Projetos web

Coleção de projetos web executáveis e containerizados.

## Projetos

Os projetos são adicionados progressivamente nas seguintes categorias:

- `projects/01-facil/`
- `projects/02-intermediario/`
- `projects/03-avancado/`

Cada projeto possui seu próprio README com descrição, funcionalidades, tecnologias, instruções de execução e testes.

### Em desenvolvimento

- [BenchLedger](projects/01-facil/benchledger/) — histórico de equipamentos, calibrações e manutenção para pequenos laboratórios.
- [Payment Sandbox API](projects/02-intermediario/payment-sandbox-api/) — API de pagamentos simulados com Spring Boot, PostgreSQL e testes automatizados. Criação inicial implementada; idempotência, reembolso via API e integração OAuth 2.0/JWT em desenvolvimento.
